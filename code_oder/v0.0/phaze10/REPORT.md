## Backend Required

### Persistent Company Messages

The frontend has no documented API for company messages, conversations, or message attachments. Persistent chat bubbles and sent attachment cards require backend support.

### Footnote-Aware Calculation

The calculate endpoint does not accept selected footnotes/options. The UI can collect which footnotes apply, but cannot truthfully claim they affect backend calculation.

### Real PDF Download

The backend export endpoint currently documents blocked PDF rendering. Real PDF download requires a backend renderer that creates a stored file and returns ready export metadata.

### Account Settings / Delete Account

The OpenAPI schema does not expose account update or delete endpoints. Account settings and delete account remain disabled/future in the frontend.
