# Frontend Docs

Frontend-owned product, design, architecture, development, and UI reference documentation.

## Ownership boundaries

| Tree | Owns |
| --- | --- |
| `docs/` | Frontend product/design/architecture/UI references and frontend documentation reports |
| `code_oder/` | Codex/AI phase instructions, phase reports, common rules, active frontend version |
| `backend_docs/` | Backend-delivered API/integration contracts only |

## Layout

```text
docs/
├── README.md
├── product_reference/
│   └── v0.0/
│       ├── PRODUCT_FLOW_NOTES.md
│       ├── UI_THEME_NOTES.md
│       ├── company_dual_nav_reference.png
│       ├── landing_reference.html
│       └── main_updated.html
└── reports/
    └── DOCUMENTATION_REORGANIZATION_REPORT.md
```

## Product reference (v0.0)

Visual and product-flow references used while building Frontend v0.0. These are **not** Codex phase outputs and are **not** backend contracts.

## Reports

Process and audit reports produced by frontend documentation tasks live under `docs/reports/`.
